RAZE Admin Exam Bot — расширенный пакет вопросов

Файлы:
- bot.php — VK Long Poll, обучение и экзамен.
- questions.json — исходные вопросы плюс дополнительные вопросы, извлечённые из приложенных правил администрации, игрового процесса, чатов и аккаунтов.

Количество вопросов: 145.

Выбор длины теста: 5, 10, 15, 20, 25, 30, 40, 50 (если столько доступно) или все доступные вопросы.

Установка на Bothost:
1. Загрузите bot.php и questions.json в корень проекта/репозитория.
2. Используйте Dockerfile с PHP 8.2 и расширением pdo_sqlite.
3. Проверьте переменные окружения VK_TOKEN и VK_GROUP_ID; OWNER_IDS — необязательные ID владельцев через запятую.
4. В настройках сообщества VK включите Long Poll API и событие message_new.
5. Пересоберите и перезапустите контейнер.

Примечание: часть длинных формулировок правил может отображаться в кнопках сокращённо из-за лимита VK на длину подписи; полный текст пункта сохранён в пояснении к вопросу. Перед экзаменом проверьте формулировки наказаний в исходных правилах.
