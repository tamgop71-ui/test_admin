RAZE Admin Exam Bot — обновлённый пакет

Файлы:
- bot.php — обработчик VK Long Poll и режимы обучения/экзамена.
- questions.json — 43 вопроса из присланного материала, с вариантами, правильными ответами и пояснениями.

Выбор длины:
5, 10, 15, 20, 25, 30, 40 вопросов или все доступные вопросы.
В текущем наборе 43 вопроса, поэтому пункт 50 не показывается.

Установка:
1. Замените bot.php и questions.json в корне репозитория, который использует Bothost.
2. Оставьте Dockerfile с установленным libsqlite3-dev и pdo_sqlite.
3. Проверьте переменные окружения VK_TOKEN и VK_GROUP_ID.
4. В настройках сообщества VK включите Long Poll API и событие message_new.
5. Пересоберите и перезапустите контейнер Bothost.

Важно: этот questions.json содержит 43 вопроса, которые были переданы в последнем файле. Он не может включать отсутствующие тексты правил, которые не приложены к текущему сообщению.
