# RAZE Admin Exam Bot — VK / Bothost

Бот для подготовки к посту администратора: вопросы с кнопками, мгновенная проверка, объяснение ответа, статистика и повторение ошибок.

## Что нужно на стороне VK
1. Включить сообщения сообщества.
2. Создать токен сообщества с правами на сообщения.
3. Узнать числовой ID сообщества и задать `VK_GROUP_ID` (без минуса).
4. Убедиться, что у сообщества включён Long Poll для сообщений. Бот также получает Long Poll server через API при запуске.

## Переменные окружения Bothost
- `VK_TOKEN` — токен сообщества (секретный, никому не отправлять).
- `VK_GROUP_ID` — числовой ID группы, например `241953865`.
- `OWNER_IDS` — необязательные ID владельцев через запятую; пока оставлено для будущих админ-команд.
- `TZ` — часовой пояс, по умолчанию `Europe/Moscow`.
- `DB_PATH` — путь к SQLite, по умолчанию `/app/data/raze.sqlite` в контейнерном примере.

## Запуск на Bothost
1. Загрузить архив в свой репозиторий GitHub или подключить репозиторий к Bothost.
2. Выбрать Dockerfile-развёртывание.
3. Добавить переменные окружения из списка выше.
4. Убедиться, что папка `/app/data` сохраняется между перезапусками контейнера (persistent storage/volume). Если постоянное хранилище недоступно, прогресс может сбрасываться при пересоздании контейнера.
5. Запустить контейнер. В логах должно появиться `RAZE Admin Exam Bot started. Questions: 40`.
6. Написать сообществу в VK сообщение `Начать` или нажать кнопку меню.

## Структура
- `bot.php` — Long Poll, обработка сообщений и кнопок, SQLite.
- `questions.json` — редактируемая база вопросов.
- `data/` — SQLite-файл создаётся автоматически.
- `Dockerfile` — окружение PHP 8.2 с PDO SQLite.

## Важно
- Не публикуй `VK_TOKEN` и не загружай его в открытый GitHub-репозиторий.
- Вопросы основаны на предоставленном пользователем тексте. Перед реальным экзаменом сверь формулировки и наказания с актуальными правилами проекта.
- Это стартовая версия. В ней 40 подготовленных вопросов; остальные пункты из исходных правил можно добавить в `questions.json` в том же формате.
